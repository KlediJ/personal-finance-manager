# Personal Finance Manager

A cross-platform desktop application for tracking, analyzing, and managing personal finances.

## Development

To run the application in development mode:

```
npm install
npm start
```

This will start the webpack dev server and the Electron application with hot reloading enabled.

## Building

To build the application:

```
npm run build
```

## Packaging

To package the application for distribution:

```
npm run package
```
