# Application Images

Place the following image files in this directory:

- `logo.png` - The application logo (for display in the sidebar)
- `icon.png` - The application icon (for taskbar, dock, window title)
- `favicon.ico` - Browser favicon (optional, for browser tabs)

## Image Specifications

### logo.png
- Recommended size: 200x60px or similar aspect ratio
- Format: PNG with transparency
- Used in: Application sidebar header

### icon.png
- Recommended size: 512x512px (square)
- Format: PNG with transparency
- Used in: Application window, taskbar, dock, installers

### favicon.ico
- Recommended size: 16x16px, 32x32px, 48x48px (multi-size ICO)
- Format: ICO
- Used in: Browser tabs when running in development mode
